# n8n--onboarding-process-
An automated email workflow built with n8n, Gmail and CSV data integration to streamline candidate communication
Automated Email Outreach Using n8n

**Project Overview**
This project automates email communication using n8n, Gmail and CSV data integration in the process of employee onboarding 

The workflow retrieves recipient information from a CSV database/submission form and dynamically generates personalised emails.

**Objectives**
- Automate repetitive email communication.
- Retrieve recipient information from structured CSV data.
- Dynamically populate email fields.
- Reduce manual administrative tasks.
- Saves time for for hiring managers 

**Technologies Used**
- n8n – Workflow automation
- Gmail – Email communication
- CSV – Data storage and recipient information
- JavaScript – Dynamic email content and data processing
- Open AI 

** Workflow Process**
1. Import recipient information from a CSV file.
2. Extract and process recipient records.
3. Validate email addresses.
4. Generate personalised email messages.
5. Send emails through Gmail.

**Skills Demonstrated**
- Workflow automation
- Data processing
- JavaScript
- API integrations
- Error handling
- Business process automation
